BUGS FOUND AND FIXED
1. Worker backfill could not finish a batch with "also remove didn't-book
   tags" on. Cloudflare's free plan allows 50 outbound calls per page load;
   reading 2+ years of appointments in 30-day windows used ~31, so a
   12-contact batch that also removed tags (~24 calls) failed midway every
   time. Now: 60-day windows (auto-falls back to 30 if HighLevel refuses),
   contact paging stops if HighLevel ignores "page", and each batch is
   sized to the calls left (max 48, BACKFILL_MAX_CALLS to raise on a paid
   plan). Worker v32 = v31 + this.
2. /book: when the chosen time was taken at the last second, the "That
   time is no longer available" message was erased 150ms later by the slot
   reload, and the date view had no place to show errors -- the customer's
   time silently vanished. The message now stays up on both views.
